# Pill-dispenser
A box dispenses a pill at the press of a button and sounds an alarm as long as the pill remains in the collection box. An LED strip, synchronized with the alarm, indicates how long the pill has been in the box: it starts green, turns yellow after 5 seconds, then red. After another 5 seconds, the red LED begins blinking.
